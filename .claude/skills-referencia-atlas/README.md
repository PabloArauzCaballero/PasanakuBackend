# Skills de referencia de Atlas

Estos documentos describen la aplicación de Atlas en React Native/Expo y se conservan únicamente como referencia para entender sus decisiones de interacción y diseño. No son instrucciones ejecutables para este repositorio: el producto aquí está implementado en Flutter. Para cambios en Pasanaku, seguir las skills Flutter activas en `.claude/skills/`, en particular las adaptaciones D4 `pasanaku-*`.
