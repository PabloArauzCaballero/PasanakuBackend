# H2.S2.M6 — referencia de soporte en errores API

Fecha: 2026-10-12

Se conserva `trazaId` mientras CU-01, CU-04, verificación de correo y subida traducen
el error API a estado de interfaz. Subida primero desenvuelve el `DioException` para
no perder ni el mensaje catalogado ni el ID. La molécula `ReferenciaDeError` dibuja
el identificador en estilo terciario pequeño; no hace nada para `null`/vacío. El
organismo genérico `EstadoError` usa ahora la misma etiqueta «Referencia».

Pruebas dirigidas (31, `All tests passed!`): estado CU-01 conserva la traza, widget
de contraseña/contrato la muestra, error de subida conserva `trazaId`, el componente
no inventa referencia cuando falta, y la pantalla de saldo verifica el caso genérico.
El `dart analyze` de todos los archivos tocados terminó con `No issues found!`.

Límite explícito: las validaciones locales y los errores de red sin request-id no
tienen referencia. El trabajo se concentra en los errores de identidad del alcance
H2 y en el render genérico de `EstadoError`; no afirma cobertura visual de cada
operación de todos los demás dominios.
