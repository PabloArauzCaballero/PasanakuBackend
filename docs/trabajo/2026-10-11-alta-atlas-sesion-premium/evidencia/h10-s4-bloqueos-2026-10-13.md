# H10.S4.M3–M5 — verificaciones de seguridad bloqueadas

Fecha: 2026-10-13. Se verificaron los recursos disponibles sin iniciar emuladores ni modificar servicios.

## H10.S4.M3 y H10.S4.M4 — Android

El sistema expone solo Windows y Chrome; `adb devices -l` no lista dispositivos conectados. Hay dos AVD configurados con **2.048 MB** cada uno y **954 MB** de RAM libre al verificar. No se inició ninguno dentro del presupuesto de memoria solicitado.

- **M3:** falta tomar una captura del sistema Android durante ingreso, alta y capturas y comprobar que esté negra/bloqueada. Las pruebas con puerto falso siguen siendo evidencia de código, no sustituyen la captura del SO.
- **M4:** falta inspeccionar el directorio temporal real antes/después del alta y comprobar que queda vacío. Los fakes/pruebas locales no demuestran el filesystem del dispositivo.

Ambas quedan `BLOQUEADO` hasta conectar un Android o disponer de RAM suficiente para ejecutar un AVD sin superar el límite local.

- La evidencia detallada de Gradle/PostgreSQL está en [H1.S6 backend bloqueado](./h1-s6-backend-bloqueado.md): no se alcanzó `127.0.0.1:5433` para generar jOOQ ni ejecutar la suite.
