# H2.S2.M5 — desplazamiento al error de alta

Fecha: 2026-10-12

El paso de contrato conserva la alerta persistente y ahora desplaza el
`SingleChildScrollView` hasta ella cuando recibe un rechazo del alta, evitando que el
error quede fuera del viewport en pantallas pequeñas. La pieza se extrajo a
`paso_contrato_de_alta.dart` y se prueba con contenido previo más alto que el
viewport.

Comando: `flutter test test/widget/paso_contrato_de_alta_test.dart --reporter expanded`.
Resultado: 1 widget test, `All tests passed!`; `dart analyze` de pantalla, componente
y prueba: `No issues found!`.
