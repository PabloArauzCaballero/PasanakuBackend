# Nivel 3 · Móviles (app)

Página visual: `Moviles.html`. La billetera vive en el teléfono. Área táctil mínima **44×44 px**.

## Componentes
- **App bar** superior: título centrado + volver (‹) + acción.
- **Tab bar** inferior: 3–5 destinos con ícono + label; activo `#1C5A3A`; CTA central opcional.
- **FAB** (56px, `#E5852B`).
- **Bottom sheet / action sheet**: panel con radio 24 arriba, handle, opciones.
- **Teclado numérico** (3×4) para montos y PIN.
- **PIN/OTP** de 4–6 dígitos para seguridad.
- **Snackbar** inferior efímero.
- **Tarjeta de saldo móvil** (encabezado verde + Recargar/Retirar).
- **Onboarding** con puntos.

## Pantallas de referencia
Home billetera · Recargar (teclado) · Detalle + bottom sheet · PIN de seguridad · Onboarding.

> Traducción a **Flutter** (`packages/diseno_flutter`) siguiendo los skills `movil-flutter` y `arquitectura-atomica`.
